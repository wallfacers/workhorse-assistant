# i18n 国际化设计

> 日期: 2026-05-31
> 状态: Draft

## 概述

为 Workhorse Assistant 前端（React 渲染层）添加国际化支持，支持中文 (zh-CN) 和英文 (en-US) 两种语言。

## 需求

- 支持语言：zh-CN（基准语言）、en-US
- 默认语言：跟随操作系统语言设置，可在设置中手动切换
- 范围：仅前端 React 组件（`src/`），Rust 后端（`src-tauri/`）不涉及
- 节奏：一步到位，所有 21 个组件全部改造
- 切换即时生效，无需重启应用

## 技术选型

**react-i18next**（i18next + react-i18next）

选择理由：
- React i18n 事实标准，成熟稳定
- hook `useTranslation()` 自然融入函数组件
- TypeScript 类型安全可配置
- React 19 + Vite 6 兼容，无需额外配置
- 插值 `{{variable}}`、语言检测、懒加载开箱即用
- 包体积 ~40KB (gzip ~15KB)，可接受

新增依赖：
- `i18next`
- `react-i18next`
- `i18next-browser-languagedetector`（系统语言检测 + localStorage 持久化）

## 文件结构

```
src/
├── i18n/
│   ├── index.ts              # i18next 初始化配置
│   ├── types.ts              # 翻译 key 的 TypeScript 类型定义
│   └── locales/
│       ├── zh-CN.json        # 中文翻译（基准语言）
│       └── en-US.json        # 英文翻译
```

## 核心架构

### 初始化

在 `src/main.tsx` 的 `createRoot()` 之前调用 `import './i18n'`，确保 i18next 在 React 渲染前完成初始化。

```typescript
// src/i18n/index.ts
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import LanguageDetector from 'i18next-browser-languagedetector';
import zhCN from './locales/zh-CN.json';
import enUS from './locales/en-US.json';

i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources: {
      'zh-CN': { translation: zhCN },
      'en-US': { translation: enUS },
    },
    fallbackLng: 'zh-CN',
    interpolation: { escapeValue: false },
    detection: {
      order: ['localStorage', 'navigator'],
      lookupLocalStorage: 'workhorse:locale',
      caches: ['localStorage'],
    },
  });

export default i18n;
```

### 类型安全

以 zh-CN.json 为基准生成翻译 key 类型：

```typescript
// src/i18n/types.ts — 自动从 zh-CN.json 推导类型
// 确保所有 t('key') 调用有编译时检查
```

配置 i18next TypeScript 后端，使 `t()` 函数的 key 参数有自动补全和类型检查。

### 语言检测优先级

1. `localStorage` 中 `workhorse:locale` 的值
2. `navigator.language`（浏览器/WebView 系统语言）
3. 回退到 `zh-CN`

## 翻译 Key 组织

JSON 采用**按组件分组**的嵌套结构：

```jsonc
{
  "common": {
    // 跨组件复用的通用词汇
    "confirm": "确认",
    "cancel": "取消",
    "close": "关闭",
    "retry": "重试",
    "copy": "复制",
    "send": "发送",
    "stop": "停止",
    "allow": "允许",
    "deny": "拒绝"
  },
  "agent": {
    // AgentRail 组件
    "placeholder": "请输入任务，交给我来完成",
    "welcome": "有什么可以帮你的？",
    // ... 状态、权限、反馈等
    "status": {
      "disconnected": "未连接",
      "connecting": "连接中…",
      "connected": "已连接",
      "failed": "连接失败"
    }
  },
  "settings": {
    // SettingsModal 组件
    // ... 主题、连接、推理、语言选择
  },
  "tasks": { /* TaskListModal */ },
  "workspace": { /* RightPanel */ },
  "terminal": { /* Terminal 组件组 */ },
  "error": { /* ErrorBoundary */ },
  "reasoning": { /* ReasoningPart */ },
  "codeBlock": { /* CodeBlock */ },
  "titleBar": { /* TitleBar */ }
}
```

### Key 命名规则

- `common` 存放跨组件复用的通用词汇
- 每个主要组件/功能区域一个顶级 key
- 含变量的字符串使用 `{{variable}}` 插值语法（i18next 标准）
- 状态类可多层嵌套（如 `agent.status.connected`）保持语义清晰
- Key 名使用 camelCase

## 组件改造模式

### 基本 hook 用法

```tsx
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation();
  return <span>{t('agent.status.connected')}</span>;
}
```

### 插值

```tsx
// 改造前
<span>深度思考 {durationSec} 秒</span>

// 改造后
<span>{t('reasoning.duration', { seconds: durationSec })}</span>
```

### aria-label / placeholder

```tsx
<button aria-label={t('common.send')}>
<input placeholder={t('tasks.searchPlaceholder')} />
```

### 改造清单

| 组件 | 预估 key 数量 | 复杂度 |
|------|:---:|:---:|
| AgentRail.tsx | ~25 | 高（含动态状态、权限流程） |
| SettingsModal.tsx | ~20 | 中（+新增语言选择器） |
| TaskListModal.tsx | ~5 | 低 |
| RightPanel.tsx | ~15 | 中 |
| Terminal 组件 (6个) | ~10 | 低 |
| ErrorBoundary.tsx | ~3 | 低 |
| ReasoningPart.tsx | ~4 | 低（含插值） |
| 其他小组件 | ~8 | 低 |
| **合计** | **~90** | — |

## 语言切换 UI

在 SettingsModal 的"外观"区域新增语言选择器：

- 位于"主题"选项下方
- 使用原生 `<select>` 元素，不引入新 UI 依赖
- 选项显示：`中文 (简体)` / `English`
- 切换即时生效（i18next 的 `changeLanguage()`）
- 选择自动持久化到 localStorage

## 不做的事

- **不改造 Rust 后端** — 后端错误消息和日志保持英文
- **不做命名空间拆分** — ~90 个 key 用单一 `translation` 命名空间足够
- **不做懒加载** — 两种语言包都很小（<5KB），直接打包
- **不做 RTL 支持** — 中文和英文都是 LTR
- **不引入 plural/i18n 复杂特性** — 当前无复数场景

## 验收标准

1. `npm run lint` 通过（TypeScript 类型检查）
2. 所有 21 个组件中无硬编码中文字符串（仅翻译文件中有）
3. zh-CN 和 en-US 切换正常，UI 无布局错乱
4. 语言选择持久化，重启后保持用户选择
5. 新增 `npm run lint` 无新 warning
